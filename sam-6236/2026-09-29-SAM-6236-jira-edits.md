## SAM-6240 reshape

- New title: "[In-App] Mobile SDK enabler: app connection, triggers, overlay display and offline rules".
- It now owns the phone-side work no story owned:
  - Connecting the app and sending its screen list.
  - Sending the app version.
  - Registering test devices by QR code.
  - Trigger timing: Next App Open, contextual events, trigger delay, in-session spacing.
  - The order display rules run in.
  - Rendering the 5 formats: safe area, close button, text scaling, dimming, screen reader.
  - Which event each way of closing raises.
  - An opt-out call for the client app.
- Stated non-goal: no template registration for Custom HTML.
- P0 kept at 8. Two new P0s: the app connects, and each close method raises the right event. Two old P0s moved to P1 Test Cases: clock change (SAM-6290) and malformed event (SAM-6291).
- Carried over from SAM-5465: the screen-reader focus rule and "a malformed campaign never crashes the app".
- 5 open questions are listed in the ticket.

## Plain-language pass (same day)

The user asked for no internal codes in the tickets. The epic, all 7 stories and all 51 Test Cases were rewritten:

- Requirement codes, screen codes, element codes and PRD section references were removed.
- Screens and fields are now named: "In-app settings page", "New overlay window", "Eligibility window" field, and so on.
- Acronyms were replaced with what they mean:
  - "OCA S1/S2 incident" became "an open severity 1 or 2 incident on the service".
  - "ITM transactional message" became "a transactional message such as an OTP or booking receipt".
- In the epic, the "Where each ID lives" table became "Where each screen lives".
- Acceptance criteria are now numbered lists. Each story lists its Test Cases with a short name instead of a criterion code.
- A Jira text search for the old codes across all 59 tickets returns nothing.
